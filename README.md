# rlbind
Open-Source Rogue Lineage Keybinder

Re-bind keys to whatever you want, your re-binds aren't active when you are casting the spell Gate. That's all this software does, more in the future.
If anti-virus pops up, create an exception. This software is open-source so you can look through the source code if you like. 

Rogue Lineage: https://www.roblox.com/games/3016661674/Rogue-Lineage


## Instructions for setup: 

- Download [installer.iss](https://github.com/jalpaid/rlbind/blob/main/installer/RogueKeybinds-Setup.exe)
- Run the installer.
- Once the software is running, load up rogue lineage and check for the gate spell detection.
- If correctly detected, your keybinds will disable when the gate spell is casting.
